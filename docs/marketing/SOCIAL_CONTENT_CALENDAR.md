## Strategy

**Primary channel:** LinkedIn — B2B audience, longer-form performs, founder-led voice
**Secondary channel:** Twitter/X — developer/marketer overlap, thread format, real-time conversation
**Tertiary channel:** Instagram — visual carousel format for template previews, behind-the-scenes

**Content pillars (rotate weekly):**
1. **Problem awareness** — The cost of blank-page syndrome
2. **Template deep-dives** — One template, one use case, one result
3. **Workflow proof** — Screen recordings, time-lapses, real outputs
4. **User stories** — Beta user wins (anonymized or with permission)
5. **Education** — Content frameworks, hook formulas, CTA patterns
6. **Product updates** — New templates, features, pricing clarity

**Voice:** Practitioner, not marketer. Specific > generic. Show, don't tell.

## Risk Mitigation

| Risk | Mitigation |
|------|------------|
| Low beta engagement | Pre-recruit 5 vocal beta users committed to posting |
| Launch day technical issues | Staging deploy + smoke test Jan 31; rollback plan |
| Negative feedback (pricing, features) | FAQ ready; founder responds personally; iterate fast |
| Product Hunt bury | Hunter confirmed; 30+ team/beta/network upvotes committed; comments seeded |
| Content fatigue | Hard stop Sundays; batch-create Sat; recycle best performers at 90 days |
