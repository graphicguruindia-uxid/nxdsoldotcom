## Content Production Workflow

```
Ideation → Outline → Draft → Edit → SEO Optimize → Design Assets → Publish → Distribute
   │         │        │       │         │              │           │          │
  CMO      CMO     Writer  CMO      CMO           Designer    CMO       CMO
```

### Per Post Checklist

- [ ] Keyword research (Ahrefs/Ubersuggest)
- [ ] Outline with H2/H3 structure
- [ ] Draft (target word count ±20%)
- [ ] Edit for clarity, voice, conversion
- [ ] On-page SEO: title, meta, headers, internal links, schema
- [ ] Create featured image (1200x630) + social cards
- [ ] Publish to /insights with proper URL structure
- [ ] Submit to Google Search Console
- [ ] Share: LinkedIn (CEO + CMO), Twitter, newsletter
- [ ] Add to relevant email sequence
